Features

Everything an emergency binder should be

🔐

Encrypted vault

Random vault key wrapped by your master password and a one-time recovery code. Documents are encrypted before they touch the disk.

📄

Document vault

Store PDFs and files with categories, status, live search and fast filters for Identity, Insurance, Vehicle, Medical and more.

⏳

Expiry tracking

Passports, policies and licences get expiry dates with a readiness view that surfaces what is about to lapse.

🚨

Emergency mode

One click away: your emergency profile, critical documents and trusted contacts, laid out for someone else to act on.

🧭

Readiness score

A project-defined completeness score, activity log and demo data so the system is easy to present and easy to fill in.

🛡️

Locks itself

Salted PBKDF2-HMAC-SHA256 password hashing, optional Google sign-in for identity verification, and a 15-minute inactivity lock.

Install

Running in two commands

Requires Python 3.11 or newer. Everything stays on your machine.

# clone
git clone https://github.com/rajgupta3345/lifevault.git
cd lifevault

# install and run
python -m pip install -r requirements.txt
python main.py

On Windows you can just double-click Run_LifeVault.bat — it checks for Python, installs the requirements and launches the app.

Prototype notice. LifeVault is a college/local prototype, not a production security, medical, legal or emergency-response product. Data is stored on your computer — keep your recovery code safe, and don't use demo data as real emergency information.
